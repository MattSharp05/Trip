# Trip

An iPhone travel app built around three ideas: **Organize** (a wallet for every booking and
document), **Plan** (a big interactive map with the itinerary underneath) and **Discover**
(what's happening where you're going, on your dates).

Built with Expo (React Native + TypeScript). During the demo phase it runs in **Expo Go**.
