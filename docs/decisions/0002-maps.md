# 0002 — Map rendering (provisional until the map spike)

**Context.** The Plan screen's map is the product's centrepiece: dark, photo pins, a day's route,
fly-to on selection, and a cinematic globe with great-circle flight arcs. In Expo Go the options are
`react-native-maps` (Apple Maps; native; little styling) or MapLibre GL JS inside
`react-native-webview` (full styling, globe projection, free OpenFreeMap tiles; web gestures).

**Decision (provisional).** City map: `react-native-maps` with Apple Maps in dark mode, custom photo
markers and polylines. Flight globe: MapLibre GL JS globe in a WebView with our own dark style.
A spike ticket builds both on the phone; Matthew picks at the Plan checkpoint.

**Consequences.**
- No API keys or costs for either.
- Two map technologies if the default holds. If Apple Maps can't match the look, MapLibre takes the
  city map too, and one WebView map component serves both.
- The map component sits behind a small interface (`TripMap`: pins, route, selected id, fitTo,
  flyTo) so the choice can change without touching Plan.
